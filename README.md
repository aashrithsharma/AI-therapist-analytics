# 🧠 AI Therapist Analytics

> End-to-end data analysis of a mental health therapy platform — covering user retention, cohort analysis, revenue metrics, session funnel, and therapist performance.

---

## 📌 Overview

This project analyzes a sample dataset from a fictional AI-assisted therapy platform. Using Python (Pandas, NumPy, SQLite) and Google Colab, it performs structured data cleaning, SQL-based querying, and derives actionable business insights around user behavior and therapist performance.

## 📊 Dataset Description

The dataset (`SAMPLE_DATA.xlsx`) contains **3 sheets**:

| Sheet | Key Columns | Description |
|---|---|---|
| **Users** | `user_id`, `signup_date`, `source` | 500 unique users and their acquisition source |
| **Sessions** | `session_id`, `user_id`, `session_date`, `session_number`, `therapist_id`, `fee` | All therapy sessions (up to session 5 per user) |
| **Feedback** | `session_id`, `rating`, `review_text` | Post-session ratings and text reviews |

## 🔍 Analysis Sections

### 1. 🧹 Data Cleaning
- Loaded all three sheets separately
- Handled missing values: `fee` filled with **median**, `therapist_id` filled with **mode**, `rating` filled with **median**
- Removed duplicates across all tables
- Verified session number sequences per user (0 invalid sequences found)

### 2. 📅 Cohort Analysis
- Grouped users by **month of their first session** (cohorts span Jan–Jul 2025)
- Tracked retention through **Session 2, 3, and 4** for each cohort
- Sample cohort retention rates:

| Cohort Month | Total Users | % Reached S2 | % Reached S3 | % Reached S4 |
|---|---|---|---|---|
| 2025-01 | 62 | 59.7% | 37.1% | 14.5% |
| 2025-02 | 74 | 60.8% | 36.5% | 23.0% |
| 2025-04 | 91 | 57.1% | 33.0% | 18.7% |
| 2025-05 | 96 | 61.5% | 32.3% | 16.7% |

### 3. 🌀 Session Funnel
- **500 users** completed Session 1
- **281 (56.2%)** returned for Session 2
- **169 (60.1%** of S2 users) completed Session 3

### 4. 📉 Drop-off Analysis
Identifies the last session each user attended:

| Last Session | Users Dropped | % of Total |
|---|---|---|
| Session 1 | 219 | 43.8% |
| Session 2 | 112 | 22.4% |
| Session 3 | 72  | 14.4% |
| Session 4 | 49  | 9.8%  |
| Session 5 | 48  | 9.6%  |

> 📌 **Key Insight:** The biggest drop-off is after the very first session (~44% of users don't return).

### 5. 💰 Revenue Analysis
- **Total platform revenue:** `$803,500`
- Revenue broken down by: **user**, **cohort month**, and **therapist**
- Bonus eligibility check: therapists with >10 sessions/month earn a **20% bonus** on monthly revenue

### 6. ⭐ Rating vs. Retention Correlation
- Calculated average rating per user and correlated with retention (returning vs. one-time)
- Correlation coefficient: **-0.021** → Very weak, suggesting ratings alone don't predict whether a user returns

## 📈 Key Business Insights

1. **High early drop-off (43.8% after Session 1)** — The platform needs stronger onboarding hooks to convert first-time users into repeat clients.
2. **S2→S3 retention is stronger (60.1%)** — Users who commit to a second session are significantly more likely to continue.
3. **Ratings don't predict retention** — A near-zero correlation suggests non-rating factors (therapist match, scheduling, cost) drive churn.
4. **Cohort revenue peaks in May 2025 ($153,600)** — Could indicate seasonal demand or marketing campaigns.
5. **Therapist 37 generates highest revenue ($24,300)** — Identifying top performers can help guide resource allocation.
